# 验收截图索引

本目录保存桌面宠物的验收截图。**只有 `v1.0.2-*` 前缀的文件代表当前版本**，其余为历史里程碑留痕，不应作为当前 UI 或行为的验收依据。

## 现行证据

| 文件                               | 内容                                   | 版本   |
| ---------------------------------- | -------------------------------------- | ------ |
| `v1.0.2-pet-window-2d.png`         | 2D 占位渲染的桌宠窗口                  | v1.0.2 |
| `v1.0.2-pet-window-3d.png`         | 官方 Q 版 3D 与对白气泡                | v1.0.2 |
| `v1.0.2-settings.png`              | 设置页 · 形象（形象渲染、模型大小）    | v1.0.2 |
| `v1.0.2-settings-relationship.png` | 设置页 · 关系（好感、情绪、情节记忆）  | v1.0.2 |
| `v1.0.2-settings-ai.png`           | 设置页 · AI（DeepSeek 开关与运行资源） | v1.0.2 |

重新生成（会使用独立的临时存档目录，不影响本机真实状态）：

```bash
npm run acceptance:capture
```

脚本会把版本号写进文件名，因此截图与版本一一对应。

| ---------------- | -------------------- | ------------------------ |
