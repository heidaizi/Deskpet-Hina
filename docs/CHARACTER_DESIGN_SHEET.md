# 空崎日奈（泳装）正式角色设定表

> 项目：Deskpet 个人 macOS 桌宠  
> 版本：v1.0  
> 日期：2026-10-22  
> 用途：2D 立绘/Spine/Live2D、VRM 3D、动作与对白制作的共同角色基准  
> 使用范围：个人、本机、非商业使用；公开分发前必须重新确认授权

---

## 1. 一句话角色定位

一位来到海边参加训练、嘴上嫌麻烦却仍然认真负责的风纪委员长。桌宠表现重点是“冷淡、可靠、偶尔允许自己被照顾”，不要做成持续撒娇或只会生气的模板角色。

以下特征来自 Blue Archive Wiki 的角色资料和泳装版本资料：

- 学校：盖黑那学园
- 身份：风纪委员会委员长

### 2.1 性格层次

1. 平时怕麻烦，常用简短、略带不耐烦的语气。
2. 涉及规则、秩序和职责时会立刻认真。
3. 战斗或突发情况中冷静、果断、可靠。
4. 对 Sensei 逐渐信任后，会允许安静陪伴。
5. 亲密互动中先嘴硬、找理由，之后才流露柔软。
6. 不喜欢被当成只会撒娇的角色，也不应长期表现为粗暴或恶意。

### 2.2 台词气质

- 句子短，少用夸张语气词。
- 常用“麻烦”“适可而止”“先让我安静一会儿”一类表达。
- 高好感时不突然变成甜腻语气，而是允许更长的陪伴和更直接的关心。
- 泳装语境可提到训练、海边、旧泳装和浮圈，但不要每句都重复梗。

## 3. 本项目视觉方向

### 3.1 总体风格

- 二次元、清爽、桌面 Q 版。
- 目标是 2D 与 3D 使用同一套轮廓和配色。
- 默认安全、日常化表现，不强调湿身、身体特写或过度性化。
- 视觉比例约 4.1～4.3 头身，头部略大，便于表情和桌面识别。
- 默认放松 A-pose：手臂自然下垂，约与身体成 20～30°，不能使用 T-pose。
- 角色脚下预留透明边距，脚底锚点保持在画布约 `(170, 420)`。

### 3.2 面部

- 肤色：偏冷白，不要过度苍白。
- 眼睛：紫色虹膜，半睁、略显疲惫的日奈式眼神。
- 眼型：外眼角轻微上挑，避免圆眼萌系化过度。
- 眼妆：外眼角有红色/紫红色细线或眼影特征。
- 眉毛：细、平直，略微皱眉或放松。
- 嘴型：默认小嘴、平直；开心时仅小幅上扬。
- 表情变化应依赖眼睑、眉和嘴角，不靠大幅夸张。

### 3.3 头发

- 主色：冷白色，带非常轻微的淡紫灰阴影。
- 发量很大，长度超过腰臀，后发需要明显体积。
- 头顶有一束翘起的小呆毛。
- 两侧各有细长侧发与长发束。
- 发侧有红色发绳或少量红色发饰。
- 脸部右侧有红色发夹/红色发饰。
- 2D 需要至少 4～6 个可独立摆动的发束层。
- 3D 至少配置后发、两侧长发、刘海和呆毛的 spring bone。

### 3.4 角与光环

- 两只黑色/深紫色弯角，从头部两侧偏后的位置伸出。
- 角尖比根部更亮，呈现灰紫高光。
- 光环是深色多层破碎环，带向上/向外的尖刺结构，并有紫色发光边缘。
- 3D 可适当减少光环碎片数量，但必须保留“黑紫破碎环”的识别性。
- 光环和角应作为独立节点，方便做点击、摆动和未来换装。

### 3.5 泳装

- 款式：旧式连体学校泳装，主体为深海军蓝或近黑色。
- 前胸有白底姓名牌，官方可辨识文字为“5-A ひな”。
- 胸口有小型红色饰物/挂绳，细节可简化但不能完全消失。
- 背面为连体泳装背部线条，不做现代比基尼改造。
- 脚部默认配深色简洁凉鞋。
- 2D 小尺寸时可简化缝线和标签小字，但姓名牌区域必须保留。

### 3.6 浮圈与配件

- 大型浅蓝白色浮圈，带黑紫色翼状装饰或侧边结构。
- 浮圈体量很大，若长期跟身会占据桌面窗口并影响动画。
- 桌宠默认形象不携带完整浮圈。
- 浮圈作为可选道具，用于睡觉、待机、特殊事件或大尺寸展示。
- 若 3D 接入完整浮圈，必须单独绑定为可选节点，不能固定阻塞身体动作。

## 5. 比例与关键位置

### 5.1 2D 画布基准

- 画布：`340 × 460` CSS 像素。
- 2 倍交付：`680 × 920`。
- 脚底锚点：约 `(170, 420)`。
- 头顶不含呆毛：约 `y=65`。
- 光环顶部：约 `y=10～20`。
- 头中心：约 `(170, 145)`。
- 肩线：约 `y=205`。
- 腰部：约 `y=285`。
- 膝部：约 `y=360`。
- 脚底：约 `y=420`。

### 5.2 命中区域

| ID           | 位置                         |
| ------------ | ---------------------------- |
| `horn-left`  | 中心约 `(144, 84)`，半径 20  |
| `horn-right` | 中心约 `(196, 84)`，半径 20  |
| `halo`       | 中心约 `(170, 55)`，半径 43  |
| `head`       | 中心约 `(170, 148)`，半径 64 |
| `body`       | `(116, 218)` 至 `(224, 372)` |

正式素材可以微调，但需要同步提供新的 `hitAreas` 元数据。

### 5.3 3D 基准

- 使用 VRM 1.0 标准人形骨骼。
- 脚底为模型局部 `y=0`。
- 默认面向相机，轻微内八或自然并脚，不保持 T-pose。
- 头部与身体比例与 2D 的 4.1～4.3 头身一致。
- 光环、角、泳装姓名牌和可选手持浮圈使用独立节点。

## 6. 必需表情

### neutral｜中性

- 半睁眼、无笑容、轻微不耐烦。
- 这是最常用的默认表情。

### annoyed｜不耐烦

- 眉压低，眼睛稍眯，嘴角下压。
- 不表现成暴怒或恶意。

### embarrassed｜嘴硬害羞

- 视线略微偏开，脸颊淡红，嘴唇抿紧。
- 禁止夸张爱心眼或过度撒娇。

### sleepy｜困倦

- 眼睑明显下垂，头部略前倾。
- 可配轻微呼吸和低能量姿态。

### surprised｜惊讶

- 眼睛放大，身体小幅后仰。
- 用于突然拖拽、点击光环等意外刺激。

### soft｜放松/高好感

- 眼神稍缓，嘴角很小幅上扬。
- 只在中等以上好感或安静陪伴时出现。

## 7. 动作与交互设计

### 默认动作

| 动作             | 表现                                   |
| ---------------- | -------------------------------------- |
| `idle`           | 呼吸、光环缓转、偶尔看向鼠标           |
| `look_at_cursor` | 眼睛先跟随，头部只做较小角度运动       |
| `walk`           | 手臂自然摆动，脚步幅度小，窗口平滑移动 |
| `sleep`          | 头部前倾或坐下，光环亮度降低           |
| `wake`           | 轻微惊动，快速回到中性                 |
| `wave`           | 抬手幅度克制，不连续大幅摆动           |
| `stretch`        | 双臂上抬、肩部放松                     |

### 点击互动

| 区域     | 首选反应                        |
| -------- | ------------------------------- |
| 头部     | 中性 → 害羞 → 烦躁随重复度变化  |
| 角       | 立刻不悦，头部避开              |
| 光环     | 提醒不要乱碰，光环亮度闪动      |
| 身体     | 惊讶或无奈，避免敏感化处理      |
| 长按头部 | 先嘴硬，高好感时允许短暂放松    |
| 拖拽     | 惊讶/无奈，结束后整理头发或站稳 |

### 自主行为

- 环顾周围。
- 小幅走到屏幕另一位置。
- 伸展肩颈。
- 打个简短的招呼。
- 长时间空闲后睡觉。

### 禁止行为

- 无边界讨好。
- 长时间恶意辱骂。
- 与官方设定无关的强烈恋爱化剧情。
- 以湿身、身体特写或性暗示作为主要卖点。

## 8. 2D/3D 一致性检查

| 项目     | 2D 要求              | 3D 要求                           |
| -------- | -------------------- | --------------------------------- |
| 轮廓     | 大头、长发体积、双角 | 同比例，角与头发不穿模            |
| 眼睛     | 紫色半睁眼、红眼妆   | 标准眼骨/表情，红色妆面贴图       |
| 光环     | 黑紫破碎环           | 独立节点、可发光、可旋转          |
| 泳装     | 深色旧式连体泳装     | MToon 材质，姓名牌可读            |
| 头发     | 多层摆发             | spring bone，不穿胸和手臂         |
| 默认姿态 | 手臂自然下垂         | 放松 A-pose                       |
| 互动动作 | 20 个统一动作 ID     | 同名动作与安全回退                |
| 表情     | 六种主表情           | 映射 VRM preset，缺项回退 neutral |
| 浮圈     | 可选道具层           | 可选节点，不默认挂载              |

## 9. 推荐默认决策

在正式制作前，建议先采用以下方案：

1. 2D 先做分层 PNG/WebP 桌宠版本。
2. 3D 使用 VRM 1.0，以 MToon 为目标材质。
3. 默认不挂载大型浮圈。
4. 姓名牌保留官方可读字样“5-A ひな”。
5. 默认 Q 版比例为 4.2 头身。
6. 2D 与 3D 共用六种主表情和 20 个统一动作 ID。

## 10. 仍待确认

- 正式 2D 是否升级为 Spine 或 Live2D。
- 大型浮圈在桌宠中的出场频率。
- 3D 模型由自制、委托还是用户提供。
- 是否保留深色凉鞋，或改为更易动画的裸足/简化鞋。
- 是否制作语音；当前只规划对白和音效。
