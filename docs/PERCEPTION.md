# 感知能力

日奈可以通过本地能力了解你在做什么。全部为**可选**，缺权限时自动跳过。

## 能力一览

| 能力       | 来源                                           | 刷新                                        |
| ---------- | ---------------------------------------------- | ------------------------------------------- |
| 浏览器页面 | AppleScript 读标题/URL + `curl` 抓正文         | 60 秒缓存，明确提问时强制刷新               |
| 屏幕画面   | `desktopCapturer` 截图 → `deepseek-flash` 视觉 | 后台 8 分钟；提问时若超过 10 分钟则立即刷新 |
| 音乐       | Music / Spotify 当前曲目                       | 5 分钟缓存                                  |
| 日程/提醒  | Calendar / Reminders                           | 5 分钟缓存，仅查询已运行的应用              |

## 对话里的「操作性提问」

`shared/chat-intent.ts` 识别五类意图：

| 问法示例               | 触发     |
| ---------------------- | -------- |
| 「你知道我在做什么吗」 | screen   |
| 「我在看什么网页」     | page     |
| 「我在听什么歌」       | media    |
| 「今天有什么安排」     | schedule |
| 「现在几点了」         | time     |

命中后会在请求前读取对应数据，并生成一段强约束提示：

- 有数据：要求据此回答；
- 无数据：要求坦白说看不到，不要编造。

## 权限

| 权限     | 用途                                                      |
| -------- | --------------------------------------------------------- |
| 屏幕录制 | 截图与视觉分析                                            |
| 自动化   | 控制浏览器 / Music / Calendar / Reminders / System Events |
| 辅助功能 | 点击穿透、快捷键                                          |

打包脚本已包含 `com.apple.security.automation.apple-events` entitlement，
否则系统不会弹自动化授权框。

> 每次重新签名，屏幕录制与自动化授权都会被重置，需要重新授权并重启应用。

## 隐私

- 截图与页面内容只在本机处理；
- 需要模型理解时，发送给用户自己配置的 DeepSeek API；
- 对话窗与设置窗通过 `setContentProtection` 对截图透明；
- 感知可整体关闭：`DESKPET_PERCEPTION=0`。

## 配置

| 环境变量                     | 默认             | 说明                       |
| ---------------------------- | ---------------- | -------------------------- |
| `DESKPET_PERCEPTION`         | 开               | 设为 `0` 关闭页面/屏幕感知 |
| `DESKPET_VISION_INTERVAL_MS` | 480000           | 视觉刷新间隔               |
| `DESKPET_VISION_MODEL`       | `deepseek-flash` | 视觉模型名                 |

## 成本

视觉请求每次约 1024 tokens（图片上限）。后台 8 分钟一次，按使用量计费；
明确提问触发的是额外请求。
