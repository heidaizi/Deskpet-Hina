## 1. 结论

- **3D 调研候选**：VRoid Hub 的 `Hina Swimsuit ver.`，作者 `squill`；当前已被官方 GLB 路线取代。
- **2D 没有找到许可清晰的成品桌宠动作包**：没有发现可直接使用的 Hina 泳装 Shimeji、Spine 或 Live2D 授权下载。

- 当前路线是：3D 使用已获授权的官方 GLB；2D 继续保留占位，或后续委托分层 PNG/Spine。

## 3. 2D 素材

### 3.1 检查范围

- BOOTH：`空崎ヒナ 立ち絵`、`空崎ヒナ 差分`、`空崎ヒナ Live2D`
- nizima Live2D
- GitHub：Blue Archive Shimeji、Hina Shimeji、Blue Archive Live2D
- DeviantArt、公开作者主页和通用搜索

### 3.2 结果

没有找到同时满足以下条件的 Hina 泳装 2D 素材：

- 有明确作者和来源
- 明确允许个人桌宠或应用使用
- 包含待机、点击、拖拽、走路等动作
- 允许必要的本地格式转换
- 不依赖官方游戏资源提取

因此 2D 暂不纳入“可直接使用”清单。

### 3.3 不建议的来源

- Blue Archive 游戏内 Spine/Live2D 提取包
- “Blue Archive Wallpaper”项目中自带的游戏资源
- 从其他桌宠程序中拆出的 Shimeji 图片
- 没有作者授权、只有转载的网盘资源
- 仅能用于观看的 Pixiv/Twitter 插画

这些资源即使技术上能运行，也不适合作为正式项目素材。

## 4. 推荐执行顺序

1. 继续使用用户已获授权的官方 GLB，并保持私有目录隔离。
2. 根据实机反馈调整 3D 构图、缩放、泳圈显隐和动作语义。
3. 完善独立眨眼、嘴型和动作表现。
4. 2D 暂时继续使用程序化占位，不同时引入不清晰授权的 2D 资源。
5. 若需要正式 2D，优先委托分层 PNG/WebP 或 Spine 工程。

## 5. 重要限制

- “可下载”不等于“可以再分发”。
- “Avatar Use 允许”不等于“可以修改模型”。
- VRM 内嵌 metadata 与平台授权页面可能同时提供限制，应取更严格者。
- 本项目当前为个人非商业使用；如果以后公开发布，需要重新审查。
