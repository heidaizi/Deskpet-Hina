# Deskpet v1.0.1 发布说明

> 发布日期：2026-10-25  
> 类型：3D 阴影定位修复

## 修复

- 修正 GLTFLoader 将骨骼名中的空格转换为下划线后，脚骨查找失败的问题。
- 兼容 `Bip001 L Foot` 与 `Bip001_L_Foot` 两种名称。
- 阴影从固定 scene Sprite 改为模型根节点子节点。
- 阴影每帧跟随双脚动画后的局部位置和脚间距。
- 阴影随模型整体缩放，不再单独计算导致二次缩放偏移。
- 降低阴影尺寸、宽高比和透明度，改为更自然的脚底接触阴影。

## 验收

- 3D 全尺寸与 50% 缩放下，阴影均位于双脚中心。
- 动画播放和模型朝向变化时阴影持续跟踪。
- 完整 Electron E2E：19/19 通过。
- 安装版已重新签名并启动。
