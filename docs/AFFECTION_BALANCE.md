# 好感度平衡与扩展

> 版本：1.0  
> 更新日期：2026-10-24  
> 配置源：`content/affection.json`

## 1. 设计目标

- 好感增长来自持续、质量较高的互动，而不是短时间连续点击。
- 角色情绪可以暂时变差，但不设置好感经验衰减，避免长时间未打开造成惩罚。
- 每次好感结算之间有全局冷却，防止通过不同身体部位或不同规则绕过冷却。
- 每天有硬上限；隔天恢复部分心情和精力。
- 高等级主要解锁更自然的陪伴、信任和关心，不把日奈改写成无条件甜腻的角色。

## 2. 核心规则

| 项目             |                                数值 |
| ---------------- | ----------------------------------: |
| 每日好感上限     |                                  12 |
| 全局好感结算冷却 |                               60 秒 |
| 每日心情恢复     |                                  +6 |
| 每日精力恢复     |                                 +18 |
| 挂机休息恢复     | 每 120 秒最多一次：精力 +6、心情 +1 |
| 好感经验衰减     |                                  无 |

冷却期间仍会播放动作、对白并改变心情，只是不重复增加好感经验。

## 3. 互动收益

| 互动              | 好感经验 | 心情 |    精力 | 规则冷却 |
| ----------------- | -------: | ---: | ------: | -------: |
| 普通点击头部      |       +1 |   +2 |       0 |   2.6 秒 |
| 普通长按头部      |       +1 |   +2 |      -1 |    12 秒 |
| Lv.3 信赖长按     |       +2 |   +3 |      -1 |    14 秒 |
| Lv.4 亲近长按     |       +3 |   +4 |      -1 |    18 秒 |
| Lv.5 身体互动     |       +1 |   +2 |       0 |   4.5 秒 |
| Lv.6 亲近头部点击 |       +1 |   +2 |       0 |     4 秒 |
| 点击角/光环       |        0 | 负数 | 可能 -1 | 各自冷却 |
| 双击、拖拽        |        0 | 负数 | 可能 -1 | 各自冷却 |

所有正面好感收益仍受 60 秒全局冷却和每日 12 点上限约束。

## 4. 等级曲线

| 等级 | 累计经验 | 称号       | 主要解锁           |
| ---- | -------: | ---------- | ------------------ |
| 1    |        0 | 保持距离   | 基础互动、时段问候 |
| 2    |       12 | 逐渐熟悉   | 更坦率的点击对白   |
| 3    |       32 | 愿意陪伴   | 信赖长按对白       |
| 4    |       64 | 偶尔坦白   | 亲近长按与安静陪伴 |
| 5    |      104 | 习惯依靠   | 高好感陪伴对白     |
| 6    |      152 | 不必逞强   | 深夜关心对白       |
| 7    |      208 | 夏天的约定 | 夏日约定对白       |
| 8    |      272 | 一直在这里 | 最终陪伴对白       |

## 5. 节奏预估

按每天可获得的实际好感估算：

- 轻度使用，每天 4～6 点：
  - Lv.2：约 2～3 天。
  - Lv.4：约 2～3 周。
  - Lv.6：约 5～7 周。
  - Lv.8：约 2 个月。
- 活跃使用，每天 8～12 点：
  - Lv.2：约 1～2 天。
  - Lv.4：约 1～2 周。
  - Lv.6：约 2～3 周。
  - Lv.8：约 4～5 周。

这些是当前默认配置下的估算，后续只需调整 `affection.json` 和规则收益，不需要修改状态或 UI 代码。

## 6. 防刷与恢复

- 检查顺序是先判断全局好感冷却，再判断每日上限。
- 规则冷却和全局好感冷却相互独立。
- 全局冷却只在真正增加好感后刷新；被冷却或每日上限拦截时不会延长下一次有效时间。
- 跨本地日期时自动清零当日收益，并恢复心情与精力。
- 设置窗口读取状态时也会执行日期刷新，不要求先点击角色。
- 精力不足时，自动睡眠或休息演出可在 120 秒间隔限制内逐步恢复精力和心情，避免精力归零后永久卡在睡眠状态。
- 挂机休息只作用于心情和精力，不增加好感经验，也不会突破每日好感上限。

## 7. 当前解锁内容

- Lv.2：`head-soft` 等更坦率对白。
- Lv.3：`headpat_trusted` 信赖长按对白。
- Lv.4：`headpat_friendly` 亲近长按。
- Lv.5：`body_trusted` 与 `head_close`。
- Lv.6：深夜陪伴与关心对白。
- Lv.7：夏日约定对白。
- Lv.8：最终陪伴对白。

新增等级内容时优先通过规则 `affectionLevel` 条件和对白池解锁，不把角色逻辑写死在渲染器中。
