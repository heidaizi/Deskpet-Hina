## 11. 推荐交付顺序

1. 确认角色设定表和比例。
2. 完成正式三视图、表情和动作草图。
3. 先交付 2D P0 分层与六个基础动作，接入试玩。
4. 再完成全部 2D 动作和点击反应。
5. 以当前官方 GLB 校准脸、头发、角和光环的默认构图。
6. 完善 3D 嘴型、眨眼、动作语义和头发摆动。
7. 最终调整 2D/3D 色彩、比例和动作节奏，使切换时角色识别一致。
